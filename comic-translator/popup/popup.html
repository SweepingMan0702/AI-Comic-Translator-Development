如何取得 Gemini API Key？
  1. 前往 Google AI Studio ↗ 登入 Google 帳號
  2. 點擊左側 「Get API key」 ➜ 點 「Create API key」
  3. 選擇 「Create API key in new project」 建立獨立專案：
    • 第 1 組：專案名稱填 comic 1 ➜ 複製 Key
    • 第 2 組：專案名稱填 comic 2 ➜ 複製 Key
    • 第 3 組：專案名稱填 comic 3 ➜ 複製 Key
  4. ⚡ 提速建議：推薦使用 3 組不同 Project 的速度才不會那麼慢；若覺得速度不夠，請自行建立其他帳號的三把鑰匙加入！
